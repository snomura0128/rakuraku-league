# らくらくリーグ戦 - プロジェクト概要

## プロジェクト名
らくらくリーグ戦

## プロジェクトの目的
卓球のリーグ戦をWEB上で簡単に作成し、URL共有により参加者同士で手軽に試合結果の入力・閲覧ができるサービスを提供する。

## コンセプト
- **手軽さ**: 「調整さんのリーグ戦バージョン」をコンセプトに、面倒な登録なしですぐに使える
- **シンプル**: 30代以上の趣味の卓球プレイヤーにも分かりやすいUI/UX
- **共有型**: URLを共有するだけで参加者全員が結果入力・閲覧可能

## ターゲットユーザー
- **主要ターゲット**: 30代以上の趣味で卓球を楽しむグループ
- **利用シーン**: 
  - 会社の卓球部のリーグ戦
  - 地域の卓球サークルの大会
  - 友人同士のカジュアルなリーグ戦

## 核となる価値提案
1. **アカウント不要**: メールアドレスや面倒な登録なしで即座に利用開始
2. **直感的操作**: スマートフォンでも操作しやすいシンプルなUI
3. **リアルタイム共有**: 結果入力と同時に全参加者に反映
4. **自動集計**: 勝敗表、順位表の自動生成

## 競合との差別化
- 既存の卓球管理アプリは機能が複雑で登録が必要
- らくらくリーグ戦は「作る→共有→入力」の3ステップで完結
- 中高年でも迷わず使える設計に特化

## 成功指標（KPI案）
- リーグ戦作成数
- URL共有によるアクセス数
- 試合結果入力完了率
- リピート利用率
