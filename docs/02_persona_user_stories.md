# ペルソナとユーザーストーリー

## ペルソナ定義

### 主要ペルソナ：田中さん（52歳、会社員）
- **背景**: 会社の卓球部部長。20人程度の部員のリーグ戦を年4回開催
- **ITスキル**: スマホは使えるが、複雑なアプリは苦手。LINEとメールが主な連絡手段
- **課題**: Excelでの勝敗表管理が面倒。部員への結果共有も大変
- **目標**: 簡単にリーグ戦を作って、部員みんなで結果を入力・確認したい

### サブペルソナ：佐藤さん（45歳、主婦）
- **背景**: 地域の卓球サークル運営。月1回の親睦リーグ戦を企画
- **ITスキル**: スマホでの写真共有やグループLINEは得意
- **課題**: 手作業での集計が時間がかかる。参加者への結果報告が遅れがち
- **目標**: みんなでワイワイ結果を見ながら楽しめるツールが欲しい

## ユーザーストーリー

### 管理者（リーグ戦作成者）
1. **リーグ戦の作成**
   - リーグ戦名と参加者を入力してリーグ戦を作成したい
   - 作成後すぐに共有用URLを取得したい
   - 参加者の追加・削除を後からでもできるようにしたい

2. **参加者への共有**
   - LINEやメールで簡単にURLを共有したい
   - QRコードでも共有できると便利

3. **進行管理**
   - 試合の進行状況を一目で把握したい
   - まだ結果が入力されていない試合を確認したい
   - 必要に応じて結果を修正・削除したい

### 参加者
1. **アクセス**
   - 送られてきたURLをクリックするだけでアクセスしたい
   - アカウント作成などの面倒な手続きは不要

2. **結果入力**
   - 自分の試合結果を簡単に入力したい
   - スマホでサクサク入力できるようにしたい
   - 入力ミスをした時は修正できるようにしたい

3. **結果確認**
   - リアルタイムで順位表を確認したい
   - 他の人の試合結果も見たい
   - 自分の勝敗数や勝率を確認したい

## ユーザージャーニーマップ

### リーグ戦作成から完了まで

1. **作成フェーズ**
   - サイトアクセス → リーグ戦作成 → 参加者入力 → URL取得

2. **共有フェーズ**
   - URL共有（LINE/メール） → 参加者アクセス確認

3. **試合フェーズ**
   - 試合実施 → 結果入力 → リアルタイム反映

4. **完了フェーズ**
   - 全試合完了 → 最終順位確定 → 結果共有

## 想定される利用シーン

### シーン1：会社の卓球部リーグ戦
- 昼休みや業後の試合結果をその場で入力
- 部員がスマホで順位をチェック
- 月末の表彰式で最終順位を発表

### シーン2：地域サークルの親睦大会
- 試合後にみんなでスマホを見ながら順位確認
- 次の対戦相手を確認しながら楽しく進行
- 大会終了後にLINEグループで結果を振り返り

### シーン3：友人同士のカジュアルリーグ
- 月1回の集まりで継続的にリーグ戦
- 前回の結果を見ながら今回の対戦
- 年間チャンピオンを決定
