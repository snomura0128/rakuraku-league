# 機能要件定義

## 機能一覧

### 1. リーグ戦管理機能

#### 1.1 リーグ戦作成
- **入力項目**
  - リーグ戦名（必須）
  - 参加者名リスト（必須、最低3名から最大20名程度）
  - 台数設定（必須、1台から10台程度）
  - 試合形式（必須）
    - 1ゲームマッチ（1セット先取）
    - 3ゲームマッチ（2セット先取）
    - 5ゲームマッチ（3セット先取）
  - 説明・備考（任意）
- **出力**
  - 編集可能URL生成（管理者用）
  - 閲覧専用URL生成（参加者用）
- **処理**
  - 総当たり戦の試合組み合わせ自動生成
  - 初期状態での勝敗表・順位表作成
  - 台の初期設定（空きステータス）

#### 1.2 参加者管理
- 参加者の追加・削除（編集可能URLのみ）
- 参加者名の編集（編集可能URLのみ）
- 参加者削除時の既存試合結果の処理

#### 1.3 リーグ戦設定
- リーグ戦名の変更（編集可能URLのみ）

### 2. 試合・台管理機能

#### 2.1 リーグ戦マトリクス表示
- **マトリクス表の表示**
  - 参加者×参加者の対戦表
  - セルクリックで試合開始・結果入力
- **セル状態表示**
  - 未試合：グレー（クリック可能）
  - 試合中：オレンジ + 台番号表示
  - 完了：緑/赤 + 勝者表示・スコア表示
  - 試合不可：薄グレー（全台使用中の場合）
- **インタラクション**
  - セルクリック → 台選択 → 試合開始
  - 試合中セルクリック → 結果入力モーダル

#### 2.2 台管理機能
- **台一覧表示**
  - 台番号（1番台、2番台...）
  - 使用状況（空き/使用中）
  - 使用中の場合：対戦者名表示
  - 開始時刻表示
- **台の操作**
  - 台選択（試合開始時）
  - 強制的に台を空ける（編集可能URLのみ）
  - 台数の増減（編集可能URLのみ）

#### 2.3 試合実行機能
- **試合開始**
  - マトリクス表または試合一覧から選択
  - 台選択（空いている台から選択）
  - 試合状態を「試合中」に変更
- **結果入力**
  - 試合形式に応じた結果入力
    - 1ゲームマッチ: 勝者選択（必須）
    - 3ゲームマッチ: 勝者選択（必須）、獲得セット数入力（必須）
    - 5ゲームマッチ: 勝者選択（必須）、獲得セット数入力（必須）
  - 各セットの詳細スコア入力（任意）
    - 入力する場合: セット毎のスコア（11-9, 11-7など）
    - 入力しない場合: 勝者と獲得セット数のみ記録
  - 入力者の記録
- **試合終了**
  - 台を空き状態に変更
  - マトリクス表のセル状態を「完了」に変更

#### 2.4 結果表示・修正
- **結果表示**
  - マトリクス表での視覚的表示
  - 試合一覧（日付順・台別）
  - 個別の試合詳細
- **結果修正・削除**（編集可能URLのみ）
  - 結果の変更
  - 結果の削除（未試合状態に戻す）
  - 試合中止（台を空ける）
  - 変更履歴の記録

### 3. 集計・順位機能

#### 3.1 勝敗表
- 参加者×参加者のマトリクス表示
- 勝敗結果の○×表示
- スコア表示（入力されている場合）

#### 3.2 順位表
- **順位決定ルール**
  1. 勝数の多い順
  2. 勝数同じ場合は直接対戦の結果
  3. それでも同じ場合は勝率
  4. 最終的に同率の場合は同順位
- **表示項目**
  - 順位
  - 参加者名
  - 勝数・負数
  - 勝率
  - 試合数

#### 3.3 個人成績
- 個人別の詳細成績
- 対戦相手別の結果
- 勝敗の推移

### 4. 共有・コミュニケーション機能

#### 4.1 URL共有
- **編集可能URL**: 管理者用（結果入力・編集・設定変更可能）
- **閲覧専用URL**: 参加者用（順位表・結果の閲覧のみ）
- **ブラウザ共有機能**
  - Web Share API を使用したネイティブ共有
  - URLコピー機能
  - LINE、メール等への直接共有
- **共有方法の選択**
  - 管理者: どちらのURLでも共有可能
  - 用途に応じたURL使い分け説明

#### 4.2 通知機能
- 新しい結果が入力された時の更新表示
- リアルタイム更新（WebSocketまたはポーリング）

### 5. データ管理機能

#### 5.1 データ永続化
- リーグ戦データの保存
- 試合結果の保存
- アクセスログの記録

#### 5.2 データエクスポート
- 勝敗表のCSVダウンロード
- 順位表のCSVダウンロード
- 結果一覧のCSVダウンロード

## データモデル

### League（リーグ戦）
```
- id: string (UUID)
- admin_token: string (編集可能URL用トークン)
- view_token: string (閲覧専用URL用トークン)
- name: string
- description?: string
- table_count: number (台数)
- match_format: string (試合形式: "1_game" | "3_game" | "5_game")
- created_at: datetime
- updated_at: datetime
```

### Player（参加者）
```
- id: string (UUID)
- league_id: string
- name: string
- created_at: datetime
```

### Table（台）
```
- id: string (UUID)
- league_id: string
- table_number: number (台番号: 1, 2, 3...)
- status: string (available | occupied)
- current_match_id?: string (使用中の試合ID)
- created_at: datetime
- updated_at: datetime
```

### Match（試合）
```
- id: string (UUID)
- league_id: string
- player1_id: string
- player2_id: string
- table_id?: string (使用台)
- status: string (pending | playing | completed)
- winner_id?: string
- sets_data?: JSON (各セットのスコア詳細: [{p1_score: 11, p2_score: 9}, ...]、任意)
- sets_won_player1: number (プレイヤー1の獲得セット数)
- sets_won_player2: number (プレイヤー2の獲得セット数)
- input_by?: string
- started_at?: datetime (試合開始時刻)
- completed_at?: datetime (試合終了時刻)
- created_at: datetime
- updated_at: datetime
```

## API設計概要

### リーグ戦関連
- `POST /api/leagues` - リーグ戦作成
- `GET /api/leagues/:id` - リーグ戦詳細取得
- `PUT /api/leagues/:id` - リーグ戦更新

### 参加者関連
- `POST /api/leagues/:id/players` - 参加者追加
- `DELETE /api/leagues/:id/players/:playerId` - 参加者削除

### 試合関連
- `GET /api/leagues/:id/matches` - 試合一覧取得
- `PUT /api/matches/:id` - 試合結果更新

### 集計関連
- `GET /api/leagues/:id/standings` - 順位表取得
- `GET /api/leagues/:id/matrix` - 勝敗表取得
